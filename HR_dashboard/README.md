# HR Dashboard Project

## Описание

Современные компании сталкиваются с необходимостью глубокой аналитики HR-данных для эффективного управления персоналом. В условиях высокой конкуренции и роста затрат на найм и удержание сотрудников, бизнесу важно своевременно получать информацию о численности персонала, демографическом профиле, динамике найма и распределении сотрудников по подразделениям.

Данный дашборд был разработан для визуализации ключевых HR-метрик и обеспечения руководителей удобным инструментом принятия решений.

## Цель проекта

Создать интерактивный дашборд для анализа структуры и динамики персонала.

## Задачи проекта

- Разработать дашборд для мониторинга ключевых HR-показателей:
  - Количество сотрудников
  - Средний возраст
  - Средний срок работы в компании
- Реализовать визуализации по структуре персонала:
  - Распределение сотрудников по департаментам
  - Топ-10 должностей
  - Распределение по возрастным категориям
  - Распределение по полу
- Визуализировать динамику найма сотрудников
- Реализовать фильтрацию по департаменту, отделу, позиции, типу занятости

## План работы

1. Выгрузка данных в Power BI
2. Создание необходимых мер с использованием DAX
3. Создание макета дашборда
4. Визуализация данных и верстка дашборда
5. Настройка фильтров
6. Тестирвоание

## Инструменты

`Power BI` – основная платформа визуализации\
`DAX` – создание мер и расчетных столбцов\
`Power Query` – очистка и трансформация данных
